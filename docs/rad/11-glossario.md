# 4. Glossario (Glossary)

| Termine | Definizione |
|---|---|
| Abbonamento | piano a pagamento (Start, Pro) o gratuito (Free) del nutrizionista; determina il numero di pazienti. |
| Aderenza | misura di quanto il paziente segue il piano, calcolata dai check-in; espressa dallo stato semaforo (verde, giallo, rosso) degli ultimi giorni. È un indicatore di attenzione, non una misura clinica. |
| Agenda | funzione del nutrizionista per gestire disponibilità, visite e calendario; mostra la prossima e l'ultima visita nella scheda cliente e consente al paziente di prenotare. |
| Alternativa | alimento sostitutivo ammesso dal nutrizionista per una voce del piano; il paziente può sceglierla nel check-in. |
| Archiviato | stato di un paziente che il nutrizionista non segue più attivamente; i dati restano conservati, il paziente non si elimina. |
| B2B2C | modello in cui un'azienda (qui Cenato) vende a un'altra (il professionista) per raggiungere il consumatore finale (il paziente). |
| Barcode | codice a barre di un prodotto confezionato, usato dal nutrizionista per recuperare i valori nutrizionali. |
| Caso d'uso | descrizione di una funzione del sistema dal punto di vista di un attore, con flusso principale e flussi alternativi. |
| Check-in | conferma rapida con cui il paziente indica come è andato un pasto previsto (Seguito, Alternativa, Fuori piano, Saltato). |
| Dashboard | schermata del nutrizionista con elenco pazienti, semaforo, ultimo check-in e prossima visita. |
| Diario dei pasti | insieme dei check-in del paziente; non contiene calcoli di calorie o macro inseriti dal paziente. |
| Disponibilità | giorni e fasce orarie in cui il nutrizionista riceve, indicati alla registrazione e modificabili dal profilo. |
| Finestra di prenotazione | periodo, stabilito dal nutrizionista per ciascun paziente, in cui il paziente può prenotare la prossima visita (di norma circa un mese dopo l'ultima). |
| Fuori piano | stato del check-in per un pasto diverso da quello previsto e senza alternativa approvata. |
| Giorno tipo | giorno del piano composto una volta e copiato su altri giorni. |
| Invito | codice o link generato dal nutrizionista per collegare un nuovo paziente. |
| Macronutrienti | proteine, carboidrati e grassi. |
| Nutrizionista | nel documento, il professionista che segue i pazienti (biologo nutrizionista, dietista, medico dietologo). |
| Obiettivi nutrizionali | valori giornalieri di kcal, proteine, carboidrati e grassi che il nutrizionista stabilisce per un paziente prima di creare il piano. |
| Open Food Facts | database collaborativo e aperto di prodotti alimentari (licenza ODbL). |
| Pasto extra | pasto non previsto dal piano che il paziente segnala; non modifica l'indice di aderenza. |
| Pasto previsto | pasto del piano (colazione, spuntino, pranzo, cena) composto da voci con alimenti e quantità. |
| Paziente | persona seguita da un nutrizionista e utente finale dell'app. |
| Piano alimentare | insieme dei pasti previsti per i giorni stabiliti, composto dal nutrizionista e assegnato a un paziente, con kcal e macro calcolati. |
| Prenotazione | scelta di uno slot libero da parte del paziente; la visita è confermata subito se lo slot è ancora libero. |
| Scenario | istanza concreta di utilizzo del sistema, descritta con personaggi di fantasia. |
| Semaforo | indicatore di aderenza (verde, giallo, rosso). |
| Slot | intervallo di tempo prenotabile, ricavato dalle disponibilità e dalla durata della visita. |
| Spazio sponsor | scheda statica nella dashboard del nutrizionista nel piano Free; non è mai mostrata ai pazienti. |
